# موقع الثانوية الإعدادية الرحال بن أحمد

هذا مشروع موقع تعريفي جاهز للتشغيل محلياً.

## التشغيل
1. فك الضغط عن الملف.
2. افتح `index.html` في Chrome أو Edge.
3. الصور موجودة داخل مجلد `images`.

## ملاحظات
- الصور والشعار مأخوذة من الملفات التي أرسلها صاحب الطلب.
- قسم "آراء التلاميذ" يحتوي أسماء وآراء تجريبية فقط، وليست شهادات حقيقية.
- المساعد الموجود في الموقع نسخة تجريبية محلية بأسئلة وأجوبة محددة، وليس نموذج ذكاء اصطناعي متصل بخدمة خارجية.
- يمكن لاحقاً ربط المساعد بواجهة API حقيقية إذا رغبت.
- الموقع ومعلومات العنوان والهاتف أضيفت بناءً على معلومات منشورة على الويب، ويُنصح بمراجعتها مع إدارة المؤسسة قبل النشر الرسمي.
